How to read this dashboard

Definitions and cautions from the Power BI guide
Weighted averages only. Rows hold pre-aggregated averages with different measurement counts, so avg_pm25 is never summed — every PM2.5 average here is Σ(avg × count) ÷ Σ(count).

Units. All PM2.5 values are µg/m³. This dataset has no AQI field; do not relabel these values as AQI.

Review flags. REVIEW_HIGH_VALUE marks readings for investigation. It does not itself prove a reading is wrong.

Monthly file. Monthly figures come from the corrected gold_monthly_pm25.csv (492 station-month rows). The daily fact table is used only for "days with data" and as a fallback if the monthly file is missing or again identical to the hourly file.
